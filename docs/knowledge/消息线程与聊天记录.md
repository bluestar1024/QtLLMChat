# 消息线程与聊天记录

## overview

`MessageThread`（QThread 子类）模拟流式消息输出；`ChatRecordsWidget` 提供聊天记录管理（搜索/清空/回放）。两者共同支撑会话数据的"产生 — 展示 — 持久化 — 回放"闭环。

## architecture_design

### MessageThread（messagethread.cpp）

- 构造参数：`contentInput`（用户输入）、`context`（QList\<QVariantMap\> 上下文，预留 API 多轮对话）、`useStream`（是否流式）。
- `run()`：当前实现取全局常量 `testText_simple` 作为回复内容；流式时每 30 字符一包、间隔 500ms 发出 `newMessage`；非流式一次发完。
- `stop()`：`terminate()` + `wait()`（强制终止，非协作式取消）。
- **现状**：未发起真实 HTTP 请求；`contentInput` / `context` 目前未参与输出，为后续接入 OpenAI 兼容接口预留的接口面。

### ChatRecordsWidget（chatrecordswidget.cpp）

- 结构：头部（设置按钮 + 标题 + 搜索框 `LineEdit` + 清空按钮）+ 会话列表（`QListWidget`）。
- 模板连接器：`connectSettingButtonClick` / `connectLineEditTextChanged` / `connectSearchButtonClick` / `connectClearAllButtonClick` / `connectListItemClick` 各有 (无参) / (带 bool) 两种重载，供 MainWindow 灵活接入。
- 列表项数据：`listItemSetData` / `listItemToString` 以字符串承载会话信息（会话文件名等）。

## data_model

聊天记录文件 `chat_YYYY_MM_DD_HH_MM_SS.txt`（UTF-8），每条消息 3 行：

```
消息文本（原始 Markdown，含 <think>）
消息部件思考时长:N秒
True|False        # True=用户，False=AI
```

写入：`MainWindow::writeToChatRecordFile()` 遍历 `chatShow` 逐条拼接；回放：`MainWindow::generateCurChatRecord()` 按 3 行一组解析并重建 `MessageWidget`（`thinkTimeIndex` / `expandIndex` 恢复展开状态）。

## gotchas_and_constraints

- `MessageThread::stop()` 使用 `terminate()`，可能中断在任意位置；接入真实网络请求后应改为协作式停止（标志位 + 网络超时）。
- 聊天记录目录为可执行文件相对路径 `../../chatrecords/`，打包部署时需保证目录存在/可写，否则记录写入失败（代码中 try/catch 捕获并仅 qDebug 输出）。
- `clearAllChatRecords` 删除全部记录文件前应确认与主窗口的联动逻辑（避免正在回放的会话句柄失效）。

## coding_conventions

- 线程类通过信号（`newMessage`）与主线程通信，符合 Qt 跨线程事件模型。
- 记录文件读写统一 `QTextStream` + UTF-8（`QStringConverter::Utf8`），保证中文兼容。
