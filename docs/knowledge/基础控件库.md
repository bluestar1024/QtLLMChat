# 基础控件库

## overview

`qt_chat/` 中一组自绘/封装的基础控件，供各业务面板复用：统一容器 `Widget`、按钮（`PushButton` / `TitleButton` / `CopyButton` / `SendButton`）、输入（`TextEdit` / `TextEditFull` / `SettingEdit` / `LineEdit`）、显示（`Label` / `CustomLabel` / `ImageLabel` / `PrintLabel`）、布局（`Frame` / `Splitter` / `ListWidget` / `TextBoxWidget` / `TextWidget` / `ItemWidget`）、Web 封装（`WebEngineView` / `WebEnginePage` / `CustomWebEngineView` / `CustomMenu`）、杂项（`LoadingWidget` / `ThinkingButton` / `ThinkBackWidget` / `Doublespinbox` / `Spinbox` / `Slider` / `Language` / `GlobalVariables`）。

## architecture_design

- `Widget`：全项目 QWidget 统一基类，重写 `mouseMoveEvent` 便于拖拽相关判断；无额外样式，作为纯净容器。
- 按钮族：
  - `PushButton`：自绘圆角按钮，支持 normal/hover 双图标（如 `clearAll`、`copy`、`renewResponse` 均含 _hover 变体）。
  - `TitleButton`：标题栏最小化/最大化/关闭按钮（图标来自 images/min.png、max.png、close.png 等）。
  - `CopyButton`：复制按钮，点击后短暂显示反馈；`SendButton`：发送按钮（含 disabled 状态图标 `send_disable.png`）。
- 输入族：`TextEdit`（QTextEdit 子类，含发送按钮联动与占位）；`TextEditFull`（外壳：背景/边框色 QPropertyAnimation 动画 + 发送按钮）；`SettingEdit`（设置行输入框）；`LineEdit`（带搜索按钮）。
- Web 封装：`WebEngineView`（QWebEngineView 子类：事件过滤、右键菜单、滚轮联动、`contentsSizeChanged` 转发）；`WebEnginePage`（`acceptNavigationRequest` 拦截导航，新窗口跳转管理）；`CustomWebEngineView` / `CustomMenu` 提供定制右键菜单。
- `Language`：QXmlStreamReader 加载 XML 字典（`load(device)`），`getNames(key)` 返回该 key 的多语言文本列表；`isLoaded` 指示状态。
- 尺寸策略：各控件实现 `updateSize(qreal curDpi, qreal lastDpi)` / `saveWidgetSize` / `resetWidgetSize`，配合 `widgetSizeDict`（QMap\<QString, QVariant\>）做 DPI 自适应。

## tech_stack

- 全部基于 Qt Widgets / Gui；自绘使用 `paintEvent` + `QPainter` / `QPainterPath`（圆角、阴影、边框）。
- 动画：QPropertyAnimation（背景色/边框色/面板滑动）。
- 字体：全局使用 `msyhl.ttc`（fontFilePath），按 pointSize 常量换算 pixelSize（DPI 相关）。

## coding_conventions

- 每个控件一个 .h/.cpp 对，文件名即类名（小写开头）。
- 图标路径常量以 `xxxImagesPath` 成员命名，资源前缀 `:/images/`（`imagesDir`）。
- 头文件统一 `#pragma once` + 传统 include guard 双保险。
- 模板成员函数（`connectXxxClick` 系列）定义在头文件内，用于信号连接适配（有无 bool 参数两种重载）。

## unique_setup_and_commands

- 新增控件：仿照现有模式创建 Widget 子类，并加入 qt_chat.pro 的 SOURCES/HEADERS；图标加入 resources.qrc。
- 控件如需 DPI 缩放，实现 `updateSize` / `saveWidgetSize` / `resetWidgetSize` 三件套并登记进 `widgetSizeDict`。
