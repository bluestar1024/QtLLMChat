# 代码编辑器与语法高亮

## overview

`CodeShow` + `CodeEditor` 提供聊天中代码块的展示组件：行号、语法高亮、明暗主题、换行模式、一键复制。高亮器基于 `QSyntaxHighlighter` 自研（`StyleSyntaxHighlighter` 基类 + 4 种语言实现），配色来自 XML 主题文件。

## architecture_design

- 组件关系：`CodeShow`（外壳：顶栏 + CodeEditor）→ `CodeEditor`（QTextEdit 子类 + `LineNumberArea`）→ `StyleSyntaxHighlighter`（基类）→ Cxx / Python / Lua / Glsl 高亮器。
- `CodeShow` 顶栏：语言标签 + 三个按钮（`toggleThemeStyle` 明暗切换 / `setLineWordWrapMode` 换行 / `copyCode` 复制），按钮图标按明暗主题切换（light/dark 两套 PNG）。
- `CodeEditor`：
  - `highlighters`（QHash\<QString, StyleSyntaxHighlighter*\>）按语言名缓存高亮器实例，`highlightCode(text, lexer)` 选择并应用。
  - `updateLineNumberAreaWidth` 依据内容行数调整行号栏宽度；`resizeEvent` 同步行号区域位置。
  - `adjustHeight`（public slot）依据文档高度自适应控件高度。
- 主题：`SyntaxStyle` 从 XML 读取（`config/dark_theme.xml` 默认 / `light_theme.xml`），`codeThemeFilePath` 为可变全局量，`CodeShow::applyDarkStyle` / `applyLightStyle` 应用。

## tech_stack

- Qt Widgets（QTextEdit / QWidget / QLabel）、QtGui（QPainter / QTextCursor / QFontDatabase / QSyntaxHighlighter）。
- 高亮规则数据：XML（cpp.xml / python.xml / lua.xml / glsl.xml），qrc 内嵌。

## coding_conventions

- 高亮器构造接收 `QTextDocument*`，规则以正则 `QRegularExpression` 配置。
- 行号区域类 `LineNumberArea` 独立文件，通过接口与 CodeEditor 通信。

## unique_setup_and_commands

- 新增语言高亮：实现 `StyleSyntaxHighlighter` 子类 + 对应 XML 规则文件 + 在 CodeEditor 构造中注册到 `highlighters` 表。
- 修改 XML 主题/规则后需重新编译（qrc 内嵌资源）。
