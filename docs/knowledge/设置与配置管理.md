# 设置与配置管理

## overview

`SettingWidget`（右侧滑出面板）提供 OpenAI 兼容 API 参数配置：baseUrl、apiKey、model、maxTokens、topP、temperature，即时持久化到 `config.txt`（qrc 资源内嵌，首次启动写入默认值）。配套控件：`SettingEdit`（输入框）、`SpinBox` / `DoubleSpinBox`、`Slider`。

## architecture_design

- UI 结构：三个文本行（baseUrl / apiKey / model，`SettingEdit` + `Label`）+ 三个数值行（maxTokens / topP / temperature，每行 SpinBox/DoubleSpinBox + Slider 联动）。
- 联动：`maxTokensSliderValueChanged` ↔ `maxTokensBoxValueChanged` 双向同步（避免信号重入，MainWindow 中 `avoidRepeatSelfFun` 标志防抖）。
- 配置读写（`loadConfig`）：打开 `:/config/config.txt`，不存在则写入默认值（`initBaseUrl` 等全局常量）；按行读取 6 个参数填充控件。
- 信号 → 保存：控件变化 → `SettingWidget` 信号（`baseUrlTextChanged` 等）→ `MainWindow` 对应槽（`onBaseUrlTextChanged` 等）→ 写回 config.txt（UTF-8，每行一个）。
- 参数范围由全局常量约束（maxTokens 0~32768、topP 0~1、temperature 0.01~1），控件 `setRange` 与 slider 映射按此配置。

## tech_stack

- Qt Widgets（QWidget / QVBoxLayout / QHBoxLayout / QPainter 自绘背景）。
- 配置持久化：QFile + QTextStream（UTF-8 逐行文本，非 QSettings）。

## coding_conventions

- 每个配置行封装为 `xxxWidget`（QWidget 容器）+ `xxxLabel` + `xxxEdit/Box/Slider`，命名前缀一致。
- 尺寸自适应：`updateSize(curDpi, lastDpi)` / `saveWidgetSize` / `resetWidgetSize` 模式与主窗口其他面板一致（`widgetSizeDict`）。

## unique_setup_and_commands

- config.txt 为 qrc 内嵌资源：程序内读取的是编译进二进制的副本；如需修改默认值需改源码常量并重新编译。
- 注意：`apiKey` 默认 `EMPTY`；baseUrl 默认指向本地 Ollama（`http://127.0.0.1:11434/v1`），目前仅供界面展示，未实际用于网络请求。
