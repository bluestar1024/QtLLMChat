# 设置与配置管理

## overview

`SettingWidget`（右侧滑出面板）提供 OpenAI 兼容 API 参数配置：baseUrl、apiKey、model、maxTokens、topP、temperature，即时持久化到项目内唯一的 `qt_chat/config/config.txt`（可读可写；qrc 中的 `:/config/config.txt` 只读，仅作文件被误删时的初始内容模板）。配套控件：`SettingEdit`（输入框）、`SpinBox` / `DoubleSpinBox`、`Slider`。

## architecture_design

- UI 结构：三个文本行（baseUrl / apiKey / model，`SettingEdit` + `Label`）+ 三个数值行（maxTokens / topP / temperature，每行 SpinBox/DoubleSpinBox + Slider 联动）。
- 联动：`maxTokensSliderValueChanged` ↔ `maxTokensBoxValueChanged` 双向同步（避免信号重入，MainWindow 中 `avoidRepeatSelfFun` 标志防抖）。
- 配置读写（`loadConfig`）：打开 `AppContext::configFilePath()`（即 `qt_chat/config/config.txt`），按行读取 6 个参数填充控件；文件不存在时从 `:/config/config.txt` 生成并写入默认值（`initBaseUrl` 等全局常量）。
- 保存：控件变化 → `SettingWidget::writeConfigLine(lineIndex, value)` 立即整文件写回（UTF-8，每行一个）。
- 参数范围由全局常量约束（maxTokens 0~32768、topP 0~1、temperature 0.01~1），控件 `setRange` 与 slider 映射按此配置。

## tech_stack

- Qt Widgets（QWidget / QVBoxLayout / QHBoxLayout / QPainter 自绘背景）。
- 配置持久化：QFile + QTextStream（UTF-8 逐行文本，非 QSettings）。

## coding_conventions

- 每个配置行封装为 `xxxWidget`（QWidget 容器）+ `xxxLabel` + `xxxEdit/Box/Slider`，命名前缀一致。
- 尺寸自适应：`updateSize(curDpi, lastDpi)` / `saveWidgetSize` / `resetWidgetSize` 模式与主窗口其他面板一致（`widgetSizeDict`）。

## unique_setup_and_commands

- 配置文件必须指向可写路径：qrc 资源（`:/...`）编译进 exe 且只读，用 `QIODevice::WriteOnly` 打开必然失败。`AppContext::initConfigFilePath()` 使用 `qt_chat.pro` 注入的 `QT_CHAT_CONFIG_DIR`（源码树内的 `config/` 目录）定位唯一的 `config.txt`，不依赖工作目录/构建目录，也不在项目目录以外读写文件；文件缺失时以 `:/config/config.txt` 为模板生成，带只读属性时启动即清除（禁止用 `QFile::copy` 生成，它会复制只读权限）。
- 写回时必须在关闭文件前显式 `QTextStream::flush()`（置于作用域块内），否则写入只进内部缓冲、`close()` 后静默丢失并因 `Truncate` 把文件清空。
- 注意：`apiKey` 默认 `EMPTY`；baseUrl 默认指向本地 Ollama（`http://127.0.0.1:11434/v1`），目前仅供界面展示，未实际用于网络请求。
