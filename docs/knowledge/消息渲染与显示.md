# 消息渲染与显示

## overview

消息渲染链路由 `MessageWidget`（单条消息）、`ThinkWidget` / `TextShow`（Markdown 文本）、`CodeShow`（代码块）、`LoadingWidget`（等待动画）、`ThinkingButton` / `ThinkBackWidget`（思考块折叠）组成。负责将流式分片文本增量渲染为富文本界面。

## architecture_design

- `MessageWidget` 构造参数全部为 `std::function` 回调（copyFun / renewResponseFun / widgetResizeFun / getSetTextingFun / executeNextFun），与 MainWindow 解耦。
- 文本预解析：`extractCodeBlocks`（``` 代码块提取 → `CodeBlock{language, code, endMarker}`）+ `parseThinkAndResult`（`<think>` 拆分思考块与结果）。
- UI 分支：`buildUserUi`（头像+文本）与 `buildAiUi`（头像 + 思考折叠按钮 + 思考内容 + 结果区 + 复制/重新生成工具条 + LoadingWidget）。
- 流式状态机：`setText` 追加分片 → 无代码块文本进当前 `TextShow`，代码块累积进当前 `CodeShow`；尺寸稳定（WebEngine `contentsSizeChanged` + `updateSizeTimer` 延时）后 `TextShow::onUpdateSize` 发 `executeNext` 续写下一段；`MessageWidget` 内含 `QEventLoop` + `checkTimer` 协调等待。
- 思考时长：`thinkTimeLengthList` 与 `thinkTimeIndex` 贯穿记录，显示在 `ThinkingButton` 上，随聊天记录持久化。

## tech_stack

- Qt Widgets（QWidget/QHBoxLayout/QVBoxLayout/QLabel）、QtCore（QTimer/QEventLoop/QRegularExpression/QMetaObject）、QtWebEngineWidgets（QWebEngineView）。
- 自研 Markdown 解析器与 HTML 渲染器（见 [Markdown解析与HTML渲染](Markdown解析与HTML渲染.md)）。

## coding_conventions

- 头文件中大量被注释的模板函数与旧接口（`connectResizeFinished` 等），保留历史痕迹，新增代码不应依赖。
- 私有成员 `xxxList` / `xxxWidget` / `xxxButton` 命名直观对应 UI 层级。

## unique_setup_and_commands

- 依赖 WebEngine 组件；运行前确认 `webengine_cache` 目录可写。
- 渲染异常时清理 `qt_chat/webengine_cache/` 缓存目录。
