# 主窗口框架

## overview

`MainWindow`（mainwindow.cpp / mainwindow.h，约 2873 行）是应用唯一主窗口：无边框自绘窗口，负责整体布局、DPI 缩放、Windows 原生消息处理、消息调度与聊天记录落盘。全局常量（路径、颜色、参数范围、测试文本）集中定义于 mainwindow.cpp 顶部。

## architecture_design

- 布局：`mainWidget`(QVBoxLayout) → `titleWidget`（标题栏）+ `splitter`（消息区/输入区）。`FunWidget` 功能栏、`SettingWidget`（右侧滑出）、`ChatRecordsWidget`（左侧滑出）均为覆盖层，通过 `QPropertyAnimation` 平移动画控制显隐。
- 无边框窗口：`nativeEvent` 处理 `WM_NCHITTEST` 等消息；`RegionEnum`（Left/Right/Top/.../Middle）划分九宫格缩放区域；`regionDivision` 计算区域，`UiStretch` / `UiDrag` 处理缩放与拖动；`applyDWMShadow` 绘制系统阴影。
- DPI 自适应：`onDpiChanged` 监听屏幕变化，`updateSize(curDpi, lastDpi)` 递归缩放子部件（各组件通过 `widgetSizeDict` 记录原始尺寸，支持 `resetWidgetSize`）。
- 消息调度：`messageQueue`(QQueue\<QString\>) 暂存分片，`messageWidgetList`(QList\<MessageWidget*\>) 管理全部消息部件，`thinkTimeLengthList` / `thinkExpandedList` 记录思考时长与展开状态。
- 聊天记录：`writeToChatRecordFile` 落盘、`saveCurChatRecord` 追加、`generateCurChatRecord` 回放、`chatRecordsGenerateItem` 生成列表项。

## tech_stack

- Qt 6.8.0 Widgets / Gui / Core / Quick（QQuickWindow 类型引用）；Windows 平台代码（qt_windows.h、dwmapi、user32）。
- QPropertyAnimation（滑出面板）、QGraphicsDropShadowEffect、QListWidget + QListWidgetItem、QThread 消息线程。

## coding_conventions

- 全局常量 extern 声明于 `globalvariables.h`，定义于 mainwindow.cpp 顶部（如 `imagesDir`、`configFilePath`、`chatRecordsDir`）。
- 槽函数命名为 `onXxx` / `xxxClicked`；私有初始化函数命名 `xxxInit`。
- 使用 `std::function` 回调而非 signal/slot 的场景较多（消息部件构造参数）。
- 大量 `qDebug()` 输出用于运行时诊断。

## unique_setup_and_commands

- 构建：qmake（见 [构建与运行](../wiki/构建与运行.md)）。
- 运行前需确保可执行文件相对路径 `../../chatrecords/` 与 `../../webengine_cache/` 可用（程序运行时创建）。
- 调试窗口问题可取消注释 main.cpp 顶部图形环境开关。
