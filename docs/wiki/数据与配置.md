# 数据与配置

## 配置文件（config.txt）

**位置**：作为资源打包于 `:/config/config.txt`，运行时通过 `SettingWidget::loadConfig()` 读取；文件不存在时以默认值创建。

**格式**：UTF-8 文本，每行一个参数，共 6 行：

| 行号 | 参数 | 默认值 | 控件 |
| --- | --- | --- | --- |
| 1 | baseUrl（OpenAI 兼容接口地址） | `http://127.0.0.1:11434/v1` | `SettingEdit` |
| 2 | apiKey | `EMPTY` | `SettingEdit` |
| 3 | model | `deepseek-r1:1.5b` | `SettingEdit` |
| 4 | maxTokens | `5000` | `SpinBox` + `Slider` |
| 5 | topP | `0.8` | `DoubleSpinBox` + `Slider` |
| 6 | temperature | `0.8` | `DoubleSpinBox` + `Slider` |

**参数范围**（`globalvariables.h` / `mainwindow.cpp` 顶部常量）：

- maxTokens：`0 ~ 32768`
- topP：`0 ~ 1`（步进 0.01）
- temperature：`0.01 ~ 1`（步进 0.01）

**保存链路**：控件值变化 → `SettingWidget` 信号（`baseUrlTextChanged` 等）→ `MainWindow` 槽函数 → 写回 `config.txt`。

## 聊天记录（chatrecords/）

**位置**：可执行文件相对路径 `../../chatrecords/`（全局常量 `chatRecordsDir`），数据库文件为 `chat_records.db`（SQLite，由 `ChatRecordStore` 封装，位于 `chatrecordstore.h/cpp`）。

**表结构**：

- `chat_session(id, file_name, created_at)`：会话表，`file_name` 沿用 `chat_YYYY_MM_DD_HH_MM_SS.txt` 命名作为会话标识，`created_at` 为创建时间。
- `chat_message(id, session_id, seq, content, think_time, is_user)`：消息表，`seq` 为会话内序号，`content` 为原始 Markdown 文本（含 `<think>` 块），`think_time` 为消息部件思考时长（秒），`is_user` 区分用户/AI 消息；按 `(session_id, seq)` 建索引。

**写入**：`MainWindow::saveCurChatRecord()` 遍历 `chatShow` 列表构建 `ChatMessageRecord` 列表（文本、思考时长、是否用户），经 `ChatRecordStore::saveMessages()` 保存——与库中现有消息逐条比较，仅从首个差异位置起删除重建（事务内）；内容完全相同时不写库（流式追加多为行内增长、消息数量不变）。

**回放**：`MainWindow::generateCurChatRecord()` 经 `ChatRecordStore::loadMessages()` 按 `seq` 升序读取消息，重建 `MessageWidget` 列表（思考时长写入 `thinkTimeLengthList`、`thinkTimeIndex`、`expandIndex` 恢复思考块状态）。

**管理**：`ChatRecordsWidget` 提供搜索（`LineEdit`，按消息内容字面匹配，`instr` 查询）、清空全部（`clearAllChatRecords` → `deleteAllSessions`）、点击加载历史会话（列表项数据承载会话 id）。

## 代码主题与语法高亮配置

`config/` 目录下 XML 文件（均打包进 qrc）：

| 文件 | 用途 |
| --- | --- |
| `dark_theme.xml` | 代码深色主题（默认，全局 `codeThemeFilePath`） |
| `light_theme.xml` | 代码浅色主题（`CodeShow::toggleThemeStyle` 切换） |
| `cpp.xml` / `python.xml` / `lua.xml` / `glsl.xml` | 各语言语法高亮规则 |

## 资源（resources.qrc）

统一前缀 `/`，主要分组：

- `images/`：界面图标（按钮、主题、聊天记录、发送、思考等 30+ 张 PNG）。
- `font/msyhl.ttc`：微软雅黑 Light 字体（全局默认字体，`fontFilePath`）。
- `config/`：配置文件与高亮/主题 XML。
- `mathjax/`：MathJax 3 es5 全套（tex-mml-chtml 入口 + 扩展 + 字体 + 映射表）。

## WebEngine 缓存

- 全局配置：`webEngineCacheDir = "../../webengine_cache"`，`QWebEngineProfile *sharedProfile`（`globalvariables.h`）供所有 WebEngine 页面共享。
- 运行时可清理 `qt_chat/webengine_cache/` 目录解决页面异常。
