# 消息渲染管线

本文详细说明一条 AI 回复从接收分片到最终渲染完成的完整链路，是项目中最复杂的子系统。

## 一、分片接收

```
MessageThread::run()          # 按 30 字符分片，每片 msleep(500) 后
    → emit newMessage(text)   # 发出分片信号
    → MainWindow::recvMessage(text)   # 队列暂存
    → queueMessage(text)      # 追加到 messageQueue，逐条处理
```

当前 `MessageThread` 输出内置测试文本 `testText_simple`（模拟流式），尚未接入真实 API。

## 二、消息部件构建（MessageWidget）

`MainWindow::messageStart()` 创建 `MessageWidget` 实例，构造参数包含：

- `copyFun` / `renewResponseFun`：复制、重新生成回调（`std::function`）
- `widgetResizeFun`：尺寸变化回调
- `getSetTextingFun`：是否正在设置文本的回调
- `executeNextFun`：续写下一段回调
- `thinkTimeLengthList` / `thinkTimeIndex`：思考时长记录
- `isUser`：用户消息与 AI 消息走不同 UI

### 文本预解析（构造时）

1. `extractCodeBlocks(text)`：正则提取 ```lang ... ``` 代码块，返回 `QList<CodeBlock>{language, code, endMarker}`。
2. `parseThinkAndResult(txt, think, result, thinkEnd)`：以 `<think>` / `</think>` 标记拆分思考块与结果正文。

### UI 组装

- 用户消息（`buildUserUi`）：头像（`ImageLabel`）+ 文本。
- AI 消息（`buildAiUi`）：
  - 头像 + `ThinkingButton`（思考块折叠按钮，带思考时长显示）
  - `ThinkBackWidget`（思考块背景容器）→ 内部多个 `ThinkWidget` / `CodeShow`
  - 结果区：多个 `TextShow`（普通文本/Markdown）与 `CodeShow`（代码块）交替排列
  - 底部工具条：`CopyButton`（复制全文）+ `PushButton`（重新生成）
  - 流式期间显示 `LoadingWidget`（打字动画）

## 三、流式增量渲染

- `MessageWidget::setText()` 追加文本并驱动内部状态机：
  - 结果正文（无代码块）→ 追加到当前 `TextShow`
  - 代码块内容 → 累积到当前 `CodeShow` 的 `CodeEditor`
  - 文本段落结束且尺寸稳定 → 发出 `setSizeFinished` / `executeNext`
- 尺寸稳定判定：`WebEngineView` 监听 `contentsSizeChanged`，经 `updateSizeTimer`（延时）确认后触发 `onUpdateSize`；`TextShow::onUpdateSize` 覆盖父类实现，首次稳定时发出 `executeNext` 继续下一段渲染。

## 四、Markdown → HTML 渲染

### 解析（MarkdownParser）

- `split(rawText)`：按行切分为 `rawBlock`。
- `blockParse`：逐块识别 `BlockType`（Paragraph / Headinglevel1-3 / HorizontalRules / CodeBlocks / BlockQuote / OrderedList / UnorderedList），构建 `MarkdownBlockElement` 序列；`LineElement` 内含行内元素列表。
- `inlineParse`：解析行内语法（粗体、斜体、行内代码、链接、图片等），输出 `MarkdownInlineElement` 列表。
- `refLinks`：引用链接表（QHash）。

### HTML 生成（HtmlRenderer）

- `setStyle(filename)`：加载外部 CSS 主题。
- `blockHtml(blockElem)` / `inlineHtml(line)`：分别输出块级与行内 HTML。
- `init()` / `tail()`：拼装页面头尾。

### 页面装配（ThinkWidget）

- 使用 `mathJaxCdn` 模板（HTML5 页面头 + MathJax 3 配置：`inlineMath ["$","$"]`、`displayMath ["$$","$$"]`、SVG 输出、禁用菜单）。
- `<script src="mathjax/es5/tex-mml-chtml.js">` 通过资源路径加载（`mathjaxScriptPath`）。
- `webEngineView->setHtml(fullHtmlText, base)`：base 指向工作目录上级（保证相对资源 URL 可解析）。
- 表格：`getTable(text)` 解析 `|` 管道符表格 → `TableInfo`（行/列/对齐），`getAlignmentClass` 映射对齐 CSS 类。

## 五、代码块渲染（CodeShow / CodeEditor）

- `CodeShow` 顶栏：语言标签（`label`）+ 三个按钮（明暗主题切换 `toggleThemeStyle`、换行模式 `setLineWordWrapMode`、复制 `copyCode`）。
- `CodeEditor`：`QTextEdit` 子类，左侧 `LineNumberArea` 行号栏；`highlightCode(text, lexer)` 依据 `lexerName` 从 `highlighters` 表取对应 `StyleSyntaxHighlighter`。
- 高亮器选择：`cpp` / `python` / `lua` / `glsl` → 对应 Cxx / Python / Lua / Glsl 高亮器；XML 规则文件来自 `config/`（`cpp.xml` 等）。
- 明暗主题：`SyntaxStyle` 从 `dark_theme.xml` / `light_theme.xml` 加载配色（背景、前景、关键字、字符串、注释等）。

## 六、结束与收尾

- `MessageThread` 发送完毕 → `MainWindow::messageFinish()`：移除 `LoadingWidget`、记录思考时长、触发聊天记录落盘（`writeToChatRecordFile`）。
- 重新生成：`renewResponseButton` → `MainWindow::messageRenewResponse()`（当前为空实现）→ 未来重建该消息部件。
