# 项目架构

## 总体分层

```
┌────────────────────────────────────────────────────────────┐
│ MainWindow（无边框主窗口：DPI/缩放/窗口消息/布局管理）         │
├───────────┬───────────────┬───────────────────────────────┤
│ TitleWidget │  FunWidget     │  SettingWidget（右侧滑出）     │
│ （标题栏）   │  （功能栏）     │  ChatRecordsWidget（左侧滑出） │
├───────────┴───────────────┴───────────────────────────────┤
│ ListWidget（chatShow，消息列表容器）                         │
│   └─ ItemWidget × N                                        │
│        └─ MessageWidget（单条消息：用户 / AI）                │
├────────────────────────────────────────────────────────────┤
│ TextEditFull（chatInput，输入框 + 发送按钮，底部）            │
└────────────────────────────────────────────────────────────┘
```

主窗口通过 `Splitter` 划分消息区与输入区；设置面板与聊天记录面板以 `QPropertyAnimation` 从左右滑出/收起。

## 模块职责

### 1. 主窗口框架（mainwindow.cpp / mainwindow.h）

- 无边框窗口：`nativeEvent` 处理 Windows 消息（`WM_NCHITTEST` 等），`RegionEnum` 划分九宫格缩放区域与标题/按钮区域，支持拖拽移动、边缘拉伸、双击最大化。
- DPI 自适应：监听屏幕变化（`onDpiChanged`），按 `curDpi / lastDpi` 比例缩放各子部件（各 Widget 提供 `updateSize` / `resetWidgetSize` 接口，尺寸记录于 `widgetSizeDict`）。
- 消息调度：持有 `messageQueue`（消息队列）、`messageWidgetList`（消息部件列表）、`thinkTimeLengthList`（思考时长）、`thinkExpandedList`（思考块展开状态）。
- 聊天记录：`writeToChatRecordFile` / `saveCurChatRecord` / `generateCurChatRecord` / `chatRecordsGenerateItem` 负责落盘与回放。

### 2. 消息渲染链路（messagewidget → thinkwidget / textshow / codeshow）

- `MessageWidget`：单条消息部件。构造时解析 `extractCodeBlocks`（提取代码块）与 `parseThinkAndResult`（拆分 `<think>` 思考块与结果文本）；用户消息与 AI 消息走不同 UI 分支（`buildUserUi` / `buildAiUi`）。
- `ThinkWidget`（思考块容器）：内部 `WebEngineView` 承载自研 Markdown 渲染结果；`TextShow` 继承自 `ThinkWidget`，用于结果文本（增加 `executeNext` 流式续写信号）。
- `CodeShow`（代码块容器）：`CodeEditor` + 顶栏（语言标签、主题切换、换行、复制按钮）。
- 流式更新：`MessageWidget` 内含 `QEventLoop` 与 `QTimer`（`checkTimer`），配合 `setText` 增量追加文本；`TextShow::onUpdateSize` 在尺寸稳定后发出 `executeNext` 继续下一段。

### 3. Markdown 解析与渲染（markdown_parser / html_renderer）

- `MarkdownParser`：`split` 切分原始文本 → `blockParse` 生成 `MarkdownBlockElement` 序列（`BlockType`：段落/标题1-3/分隔线/代码块/引用/有序列表/无序列表）；`inlineParse` 处理行内元素。
- `HtmlRenderer`：`blockHtml` 输出块级 HTML，`inlineHtml` 输出行内 HTML，`setStyle` 可加载外部 CSS；最终页面由 `ThinkWidget` 组装为含 MathJax 的完整 HTML（`mathJaxCdn` 模板 + `tex-mml-chtml.js`），通过 `WebEngineView::setHtml(html, base)` 加载。
- 表格支持：`ThinkWidget` 内 `TableInfo` 结构解析管道符表格，`getAlignmentClass` 生成对齐 CSS 类。

### 4. 代码高亮（codeeditor / stylesyntaxhighlighter / syntaxstyle）

- `CodeEditor`（QTextEdit 子类）：行号区域（`LineNumberArea`）+ 语法高亮，`highlightCode(text, lexer)` 按语言名选择高亮器。
- 高亮器：`StyleSyntaxHighlighter`（基类）→ `CxxHighlighter` / `PythonHighlighter` / `LuaHighlighter` / `GlslHighlighter`。
- 主题：`SyntaxStyle` 从 XML 加载（`config/dark_theme.xml` / `light_theme.xml`），`codeThemeFilePath` 全局可切换。

### 5. 参数设置（settingwidget / settingedit / spinbox / doublespinbox / slider）

- `SettingWidget` 提供 baseUrl、apiKey、model 三个文本框与 maxTokens（SpinBox+Slider 联动）、topP、temperature（DoubleSpinBox+Slider 联动）。
- 配置读写：`loadConfig` 读取 `:/config/config.txt`（不存在则写入默认值）；文本变更信号通过 `MainWindow` 转发保存（`writeConfig` 链路，信号：`baseUrlTextChanged` 等）。
- 保存方式：每个控件值变化时即时写回 `config.txt`（UTF-8，每行一个参数）。

### 6. 聊天记录（chatrecordswidget）

- 左侧面板：搜索框（`LineEdit`）、清空按钮（`clearAllButton`）、会话列表（`QListWidget`）。
- 记录格式：`chat_YYYY_MM_DD_HH_MM_SS.txt`，UTF-8 文本，每条消息三行：`消息文本`、`消息部件思考时长:N秒`、`True/False`（是否用户消息）。
- 回放：点击列表项 → `generateChatRecord` 读取文件重建消息部件。

### 7. 消息线程（messagethread）

- `MessageThread`（QThread 子类）：`run()` 内按 30 字符分片、每片 500ms `msleep` 发出 `newMessage` 信号。
- **当前为模拟输出**：内容取自全局常量 `testText_simple`，`stop()` 直接 `terminate()+wait()`；`context` / `contentInput` 已留作真实 API 入参。

### 8. 基础控件库（widget / label / pushbutton / copybutton / imagelabel 等）

- `Widget`：统一 QWidget 基类，重写 `mouseMoveEvent`（供拖拽判断）。
- `PushButton`：自绘圆形/圆角按钮，支持 hover 图标切换。
- `CopyButton`：消息复制按钮，点击后短暂显示"已复制"。
- `ImageLabel` / `PrintLabel` / `CustomLabel`：图标、可打印文本、自定义样式标签。
- `TextEdit` / `TextEditFull`：输入框（支持高亮、发送按钮、背景色/边框色动画）。
- `Frame` / `Splitter` / `ListWidget`：容器与分割控件。
- `LoadingWidget`：等待动画；`ThinkingButton` / `ThinkBackWidget`：思考块折叠按钮与背景。
- `CustomMenu` / `CustomWebEngineView` / `WebEngineView` / `WebEnginePage`：右键菜单与 Web 视图封装（`WebEnginePage::acceptNavigationRequest` 控制新窗口/导航）。
- `TitleButton` / `TitleWidget`：窗口控制按钮（最小化/最大化/关闭）与标题栏。
- `Language`：XML 多语言字典加载（`getNames(key)` 返回多语言文本列表）。

## 关键数据流

```
用户输入 → TextEditFull → MainWindow::sendMessage
        → MessageThread（run 流式）→ newMessage 信号
        → MainWindow::recvMessage → MessageWidget::setText（增量渲染）
        → TextShow::onUpdateSize（尺寸稳定）→ executeNext → 下一段
        → messageFinish → 保存聊天记录（writeToChatRecordFile）
```
