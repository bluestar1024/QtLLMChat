| 编译器 Kit | `Desktop Qt 6.8.0 MSVC2022 64bit`（主）、`Desktop Qt 6.8.0 llvm-mingw 64-bit`（备选） |

## 工程配置（qt_chat.pro 要点）

```
QT += core gui 3dcore            # 基础 + Qt3D
QT += widgets webenginewidgets   # 控件 + WebEngine
CONFIG += c++11                  # 实际编译为 C++17（Qt 6 默认/提升）
DEFINES += UNICODE _UNICODE QT_DEPRECATED_WARNINGS
SOURCES/HEADERS                  # 全部源文件（约 50 个组件）
RESOURCES += resources.qrc       # 图片/字体/配置/MathJax 资源
```

## Qt Creator 构建

1. 打开 `qt_chat.pro`。
2. 选择 Kit：`Desktop Qt 6.8.0 MSVC2022 64bit`。
3. 构建目录（shadow build）：`qt_chat/build/Desktop_Qt_6_8_0_MSVC2022_64bit-{Debug|Release|Profile}`。
4. 直接运行；可执行文件位于构建目录的 `release/` 或 `debug/` 子目录。

## 命令行构建

```powershell
# 以 MSVC2022 为例（需先进入 Qt 与 MSVC 环境）
cd D:\yangxiaodong\BaiduSyncdisk\git\QtLLMChat\qt_chat
D:\ProgramData\QT\Qt6\6.8.0\msvc2022_64\bin\qmake.exe qt_chat.pro -spec win32-msvc "CONFIG+=qtquickcompiler"
nmake release    # 或 mingw32-make / jom
```

## 常见问题

- **窗口/图形异常**：`main.cpp` 顶部留有大量被注释的图形环境开关（`QSG_RHI_BACKEND`、`QT_ANGLE_PLATFORM`、`QTWEBENGINE_CHROMIUM_FLAGS` 等），必要时可取消注释调试；当前启用 `QT_ENABLE_HIGHDPI_SCALING=0` 并按屏幕 DPR 设置 `QT_SCALE_FACTOR`。
- **消息无真实回复**：`MessageThread::run()` 目前输出内置测试文本，接入真实 API 前界面回复为模拟内容，属预期行为。
- **聊天记录目录**：若运行后找不到记录文件，检查可执行文件相对路径 `../../chatrecords/` 是否存在（目录不存在时程序会尝试创建）。
