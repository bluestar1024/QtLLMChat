# 测试原型（test/）

`test/` 目录存放开发过程中的原型与实验项目，不属于主应用（`qt_chat/`）交付范围，且已被 `.gitignore` 排除（`test/`）。

## 子项目一览

| 目录 | 类型 | 内容 |
| --- | --- | --- |
| `base_window/` | qmake | 无边框基础窗口原型 |
| `ctitle/` | qmake | 自定义标题栏实验 |
| `ui_border_result/` | qmake | UI 边框/圆角效果验证 |
| `webbackground/` | qmake | WebEngine 背景渲染实验（含 mathjax 副本） |
| `webbg/` | qmake | WebEngine 背景展示实验 |
| `windowtitle/` | qmake | 窗口标题栏行为验证（含 images） |
| `备份/` | - | 历史代码备份（内含 `1/`、`windowtitle/`） |
| 根目录 | CMake | `webbg` CMake 版原型（Widgets + WebEngineWidgets） |

## 根目录 CMake 原型

`test/CMakeLists.txt` 定义 CMake 工程 `webbg`：

- Qt 6 优先（`find_package(Qt6 ... Widgets WebEngineWidgets)`），C++17，AUTOMOC/AUTORCC/AUTOUIC。
- 目标：`webbg`（`WIN32_EXECUTABLE TRUE`，不弹控制台）。
- 源码：`main.cpp` + `mainwindow.cpp/h`（该 `mainwindow` 为早期版本，接口与 `qt_chat` 主窗口相似但更简，含 `nativeEvent` 边框处理）。

## 用途说明

- 这些原型用于验证无边框窗口、标题栏、WebEngine 渲染、窗口阴影等技术点，是主应用 `qt_chat/` 中对应功能的前身或实验载体。
- 修改主应用涉及窗口系统/渲染相关代码时，可先在此目录搭最小复现工程验证。

## 与主应用的关系

- 主应用功能已整合进 `qt_chat/`（见 [项目架构](项目架构.md)），`test/` 下项目不再参与主构建。
- `.gitignore` 已忽略整个 `test/`，仅本地保留。
