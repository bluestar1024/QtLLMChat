# 项目概览

## 项目定位

QtLLMChat 是一个基于 **Qt 6.8.0** 的桌面 LLM 聊天客户端（Windows 平台），采用 qmake 构建。应用提供类 ChatGPT 的对话界面，支持流式输出、Markdown 渲染、数学公式（MathJax）、多语言代码高亮、聊天记录持久化等能力，全部 UI 为自绘控件（无边框窗口 + 自绘样式）。

## 核心功能

- **对话界面**：无边框自定义窗口，左侧消息列表（`ListWidget`），底部输入框（`TextEditFull`），右侧可滑出设置面板与聊天记录面板。
- **流式消息渲染**：`MessageThread` 以分片方式发出消息（当前为内置测试文本模拟，尚未接入真实 HTTP API），`MessageWidget` 负责解析 `<think>` 思考块与代码块并逐步渲染。
- **Markdown + MathJax**：自研 Markdown 解析器（`MarkdownParser`）与 HTML 渲染器（`HtmlRenderer`），通过 `WebEngineView`（QWebEngine）加载 HTML 页面，并引入 MathJax 渲染数学公式。
- **代码高亮**：`CodeShow` / `CodeEditor` 组件展示代码块，内置 C++、Python、Lua、GLSL 四种语法高亮器，支持明暗主题切换、行号、换行模式、一键复制。
- **参数设置**：`SettingWidget` 提供 OpenAI 兼容接口配置（baseUrl / apiKey / model / maxTokens / topP / temperature），持久化到 `config.txt`。
- **聊天记录**：每次会话以 `chat_YYYY_MM_DD_HH_MM_SS.txt` 写入 `chatrecords/` 目录，支持搜索、清空、点击回放。

## 技术栈

| 项目 | 选型 |
| --- | --- |
| 语言/标准 | C++（qmake 实际编译参数 `-std:c++17`） |
| 框架 | Qt 6.8.0（`core` `gui` `3dcore` `widgets` `webenginewidgets`） |
| 构建 | qmake（qt_chat.pro），Qt Creator 14.0.2 |
| 编译器 | MSVC 2022（主 Kit）、llvm-mingw 64-bit（备选 Kit） |
| 渲染 | Qt WebEngine（Chromium）+ MathJax 3（es5） |
| 高亮器 | 自研 `StyleSyntaxHighlighter`（QSyntaxHighlighter 子类）+ XML 主题文件 |

## 目录结构

```
QtLLMChat/
├── qt_chat/                  # 主应用（qmake 项目）
│   ├── build/                # 构建产物（shadow build）
│   ├── chatrecords/          # 聊天记录 txt（运行时生成）
│   ├── config/               # config.txt + 高亮/主题 XML（qrc 打包）
│   ├── font/                 # msyhl.ttc 字体（qrc 打包）
│   ├── images/               # 图标资源（qrc 打包）
│   ├── mathjax/              # MathJax 3 前端库（qrc 打包）
│   ├── webengine_cache/      # WebEngine 磁盘缓存（运行时生成）
│   ├── *.cpp / *.h           # 主应用源码（约 50 个组件）
│   ├── resources.qrc         # 资源清单
│   └── qt_chat.pro           # qmake 工程文件
├── test/                     # 原型/实验项目（CMake 或 qmake）
│   ├── base_window/          # 无边框窗口原型
│   ├── ctitle/               # 自定义标题栏原型
│   ├── ui_border_result/     # UI 边框效果原型
│   ├── webbackground/        # Web 背景原型
│   ├── webbg/                # WebEngine 背景实验
│   ├── windowtitle/          # 窗口标题原型
│   └── 备份/                 # 历史备份
├── .vscode/                  # VSCode 配置（c_cpp_properties.json 等）
├── .clang-format             # Qt 风格格式化配置
└── docs/wiki/                # 项目文档（本文档）
```

## 当前状态（重要）

- `MessageThread::run()` 目前**仅输出内置测试文本** `testText_simple`（模拟流式），未实现真实的 OpenAI/Ollama HTTP 调用；`config.txt` 中已预留 baseUrl（`http://127.0.0.1:11434/v1`）、apiKey、model 等配置项。
- 消息渲染链路（think 块解析、代码块提取、MathJax、高亮）已基本完整，是后续接入真实 API 的渲染基础。
- 全局常量（路径、颜色、参数范围）集中定义于 `mainwindow.cpp` 顶部，通过 `globalvariables.h` 的 extern 声明跨文件共享。
